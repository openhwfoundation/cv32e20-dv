## Reference Models

This directory hosts the reference models used by this project.

### Spike

Currently, the only supported model is Spike which is cloned from https://github.com/riscv-software-src/riscv-isa-sim
This is in active development and may change in a future update of this project.

- **spike-tandem.md**: description of how the Spike model is used in "lock-step" tandem mode with the Device Under Test.
- **spike-implementation.md**: describe how Spike is generated and provides an overview of the API.

### Sail

We have plans to add support for a Sail-based reference model in the near future.
